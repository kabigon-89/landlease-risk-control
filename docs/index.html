01

背景

法律知識がない私には、

この契約が正しいのか判断ができなかった

現状

発生しうるリスク

契約更新の期日を、担当者がExcelに手入力して管理している

▶︎

更新忘れによる不法占有、契約変更・解除の申出期限の徒過、支払遅滞による延滞金の発生

法律の専門知識がない職員が、多額の資金が動く不動産契約の条項を審査・作成している

▶︎

必要な条文の抜け漏れ、解釈の余地が複数ある表現等により、相手方に有利な抗弁権を与え、契約の不履行、紛争の原因となる

数年周期の人事異動により、契約時の相手方との交渉経緯や賃料等の算出方法が、契約更新時に引き継がれない

▶︎

業務が属人化していることで、過去のトラブルの再発や誤った金額の徴収、支払が生じる可能性

02

解決策

見落としへの不安を、

個人の経験ではなく 仕組みで受け止める

SOLUTION 1

更新期日管理のワークフロー化

SOLUTION 2

AIによる条文・金額算出のリスク抽出

SOLUTION 3

契約データに紐づくナレッジ蓄積

▼︎

▼︎

▼︎

確実な手続きと業務効率化

定型チェック・期日監視をシステムが代行。繁忙期の業務集中の緩和と、自動通知による契約更新漏れの防止。

心理的安全性の確保

見落としへの不安をシステムが代替。着任直後の職員でも、萎縮せず本来の政策的・専門的判断に集中。

内部統制の強化

職務分掌と監査ログをシステムに組み込み、判断根拠を事後追跡できる透明性と説明責任を確立。口頭での引継ぎが不要に。

システム概要

ServiceNowが定型的な期日管理を、

Azureがリスク判断支援を担う二層構成

LAYER 1

ServiceNow

契約更新期日が近づくと自動でチケットを起票し、担当者への通知から対応完了までを一つのワークフローとして管理する。

契約台帳テーブル

契約案件とバージョンを親子構造で保持

期日監視

契約更新の一定期間前に契約更新・終了の判断のための自動通知を実施

承認ワークフロー

関係者間の承認を期限付きで管理し、対応の遅延を防ぐ

権限・アクセス制御

契約担当部門、土地所管課等の役割に応じた操作権限をロールで統制

◀▶︎

連携

LAYER 2

Azure

契約書を条文単位に分解し、チェック観点に照らしてリスクを抽出する。AIは判断材料の提示に徹し、最終判断は職員が行う。

文書解析

契約類型・期間・用途・賃料条件をプロファイルとして抽出

リスク抽出

契約全体、条文単位のリスクを、根拠引用付きで抽出

金額検算

賃料・単価の再計算と差異提示

ナレッジ蓄積

過去の判断や個別の経緯などを蓄積

おわりに

統制は、職員を縛るためでなく

支えるためにある

コスト削減や時間短縮は、システム導入の判断に欠かせない指標である。そのうえで本システムが目指すのは、職員が抱える不安や負担を、システムが代わりに引き受けることだ。

体裁の小さな誤りを恐れて、何度も見直しを重ねる。その時間を、住民が本当に望んでいる施設は何か、限られた財源でどのように施設運営をするべきかを考えることに使う。それが、公務員の本来あるべき姿ではないだろうか。

現場で働く職員へのやさしさを起点に設計することが、一人ひとりの働きやすさ、そして効率的で効果的な行政運営を実現すると考えている。
